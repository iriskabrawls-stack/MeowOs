# Meow OS

Lightweight Linux distribution focused on Python and PySide development.

## Features

* Debian based
* LXQt desktop
* Python preinstalled
* PySide6 support
* Nuitka support
* Wine support
* EXE building tools
* Lightweight for old hardware

## Requirements

* Intel Core 2 Duo or better
* 2 GB RAM minimum
* 20 GB storage

## Components

### Meow Center

Main control center for:

* Build EXE
* Run Python Projects
* Check Updates
* System Information
* Package Installation

## Version

Current version: 0.1.0
